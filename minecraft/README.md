# 블록크래프트 (Blockcraft)

마인크래프트 스타일의 3D 블록 샌드박스 게임입니다. 푸드 클럽 앱과는 **완전히 별개인 독립 Expo 앱**이고(`minecraft/` 폴더 안에서만 동작), 게임 엔진은 외부 라이브러리·이미지·사운드 파일 없이 WebGL로 직접 구현했습니다. 모든 텍스처와 효과음은 코드로 생성합니다.

> 마인크래프트(Minecraft)는 Mojang/Microsoft의 상표이며, 이 프로젝트는 그들과 무관한 팬 스타일 구현입니다. 에셋은 하나도 가져오지 않았습니다.

## 실행

```bash
cd minecraft
npm install
npx expo start          # 터미널에서 w = 웹, a = 안드로이드, i = iOS, 또는 Expo Go 로 QR 스캔
```

- **웹**: `npm run web` → 브라우저에서 바로 플레이 (키보드 + 마우스)
- **폰**: Expo Go 로 QR 스캔. 게임은 WebView 안의 WebGL 로 실행됩니다.
- **엔진만 보고 싶다면** `game/index.html` 을 브라우저로 직접 열어도 됩니다 (저장은 브라우저 localStorage).

## 조작법

| | 터치 | 키보드 · 마우스 |
|---|---|---|
| 이동 | 왼쪽 조이스틱 | WASD / 방향키 |
| 시점 | 화면 드래그 | 마우스 (클릭하면 마우스 잠금) |
| 블록 부수기 | 화면 **길게 누르기** | 좌클릭 (누르고 있기) |
| 블록 놓기 | 화면 **짧게 탭** | 우클릭 |
| 점프 | ▲ 버튼 | Space |
| 비행 | ▲ 두 번 연속 / 🕊 | Space 두 번 / F |
| 공격 | 몬스터·동물을 **탭** (길게 누르면 연타) | 좌클릭 |
| 아이템 사용 | 핫바에서 고르고 탭 (활 발사 · 폭탄 던지기 · 음식 먹기) | 좌클릭 / 우클릭 |
| 블록·아이템 선택 | 핫바 탭 (선택된 칸을 다시 탭하면 🎒 가방) | 숫자 1~9 / 휠 / E (가방) / 휠클릭 (복사) |
| 목표 보기 | 왼쪽 위 🎯 목표 상자 탭 (메뉴 → 목표 보기) | Q |
| 메뉴 | ☰ (안드로이드 뒤로가기도 메뉴) | Esc |

## 기능

- 시드 기반 **무한 지형**: 산·평원·사막·설산, 바다/호수, 해변, 동굴, 광석(석탄·철·다이아몬드), 나무
- 블록 40종 + 기반암/물/포털, 정점 AO·면 컬링·간이 하늘빛(동굴/숲 그늘), 하루 8분의 **낮·노을·밤**(해, 달, 별)
- 물 속 헤엄·시야 효과, 자동 점프, 비행 모드, 채굴 균열 애니메이션, 파편 파티클, 효과음
- **몬스터 3종**: 좀비(쫓아와서 때림, 낮에 햇빛에 탐), 크리퍼(다가오면 점화 후 **폭발**해서 블록이 파임), 스켈레톤(거리를 두고 옆으로 돌며 **화살** 발사). 밤과 동굴·숲 그늘처럼 어두운 곳에서 나타납니다.
- **체력(♥ 10칸)**: 피격 넉백, 사망 화면과 다시 시작, 잠시 맞지 않으면 자연 회복. 메뉴에서 몬스터를 끄면 평화 모드(창작 전용)가 됩니다.
- **동물 4종**: 돼지·소·양·닭이 낮의 풀밭에 무리로 삽니다. 맞으면 도망치고, 잡으면 고기·가죽·양털·깃털이 떨어집니다. 평화 모드에서도 그대로 남습니다.
- **아이템**: 몬스터/동물이 떨어뜨리고, 통나무·돌·석탄·철광석을 캐도 나옵니다. 바닥에서 빙글 도는 아이템에 가까이 가면 끌려와서 주워집니다. 🎒 가방은 **블록 / 아이템 / 제작** 탭으로 나뉘고, **가진 것만** 보입니다.
- **블록은 무한이 아닙니다**: 예전의 '블록 목록에서 마음대로 꺼내 쓰기'를 없앴습니다. 블록을 캐면 그 블록이 아이템으로 떨어져 가방에 들어오고(풀 → 흙, 돌 → 조약돌), 놓으면 한 개씩 줄어듭니다. **광석(다이아·금·에메랄드·석탄·철)은 캐면 자원 아이템이 나오고 광석 블록 자체는 얻을 수 없어서** 놓았다 캐는 식의 무한 복사가 안 됩니다. 나무 판자·유리·벽돌·작업대·TNT·색 양털 같은 건축 블록은 제작 탭에서 재료로 만들어요 (월드에 없는 블록도 전부 만들 수 있게 해 두었습니다). 새 월드는 나무 검 · 횃불 8 · 빵 3 으로 시작하고, 처음 주운 블록·음식은 빈 핫바 칸에 알아서 들어갑니다. 예전 저장 데이터를 열면 한 번만 기본 블록(흙·조약돌·판자·통나무·유리·벽돌·횃불)을 나눠 줍니다.
- **손에 든 물건**: 화면 오른쪽 아래에 팔이 보이고, 선택한 칸의 검·도구·음식·블록이 실제 모양(납작한 아이템은 두께 있는 3D, 블록은 작은 큐브)으로 쥐어져 있습니다. 걸으면 흔들리고, 캐거나 공격하거나 블록을 놓으면 휘두르며, 칸을 바꾸면 내렸다 올립니다. 개수가 0이면 빈손입니다.
- **무기와 음식**: 나무·돌·철 검, 철 도끼(느리지만 강함), 활+화살(맞으면 몬스터가 쓰러짐), 폭탄(화약으로 제작, 지형 파괴 + 광역 피해), 날고기/구운 고기/붕대(체력 회복). 가방의 제작 탭에서 재료를 모아 만듭니다. 새 월드는 나무 검을 들고 시작합니다.
- **최종 목표 — 엔더 드래곤 처치** (왼쪽 위 🎯 목표 상자 / Q 키로 단계별 안내): 철 검 → 철 갑옷 → 엔더 진주 4개 → 엔더의 눈 4개 → 엔드 포털 열기 → 엔드 입장 → 엔드 크리스탈 8개 파괴 → 드래곤 처치
  - **엔더맨**: 키 큰 검은 몬스터. 눈을 마주치거나 때리면 화가 나서 쫓아오고 순간이동합니다. 처치하면 **엔더 진주**를 줍니다.
  - **엔더의 눈**(진주+화약) → **엔드 포털 프레임**(눈+조약돌 2개 → 2개). 프레임 8개를 가운데가 빈 3×3 고리로 바닥에 놓으면 **엔드 포털**이 열리고, 안에 서 있으면 엔드로 이동합니다.
  - **디 엔드**: 허공에 뜬 엔드 스톤 섬과 흑요석 기둥 8개. 기둥 위의 **엔드 크리스탈**이 드래곤을 계속 치유하니 먼저 부숩니다(활이 편해요). 허공으로 떨어지면 오버월드 스폰에서 다시 시작합니다.
  - **엔더 드래곤**(체력 120, 화면 위 보스 체력바): 섬 둘레를 돌다 급강하로 들이받고 불덩이를 쏩니다. 처치하면 다이아몬드·엔더 진주를 떨어뜨리고, 섬 한가운데에 오버월드로 돌아가는 포털이 생기며 클리어 패널이 뜹니다.
  - **다이아몬드**(깊은 땅속) → 다이아 검(공격 13)·다이아 갑옷, 철 주괴 6개 → 철 갑옷. 갑옷은 가방에 있으면 자동으로 입고 받는 피해가 줄어듭니다(철 35% · 다이아 55%).
- **마을과 주민**: 평평한 풀밭·사막에 마을이 드문드문 생깁니다 (월드 시드로 정해져서 같은 월드면 늘 같은 자리). 우물을 중심으로 집·대장간·푸줏간·교회·장터 가판대·울타리 친 밭·길·가로등이 있고, 사막에서는 사암으로 지어요. 🧭 **나침반**을 들면 가장 가까운 마을의 방향과 거리가 화면에 나옵니다.
  - **주민 6직업**(농부·대장장이·사냥꾼·상인·성직자·주민)은 마을 안을 어슬렁거리고, 가까이 가면 쳐다보고, 몬스터가 오면 도망칩니다. 죽지 않으며 **탭하면 거래창**이 열려요. 마을에 안 가면 안 만들어지고, 멀어졌다 돌아오면 다시 나타납니다.
  - **거래**는 에메랄드로 합니다. 에메랄드는 깊은 땅속 광석에서 나오고, 밀·당근·철·고기 같은 걸 주민에게 팔아도 얻어요. 에메랄드로는 횃불·랜턴·부싯돌과 철·나침반·시계·철 곡괭이/검/갑옷·활·물약·황금사과 등을 삽니다.
- **빛과 횃불**: 횃불·랜턴·빛돌·모닥불 같은 **빛나는 블록**이 주변을 실제로 밝힙니다 (빛은 14칸까지 한 칸마다 약해지고 벽에 막힘, 모서리마다 부드럽게 번짐). 밝은 곳에는 몬스터가 안 생기고, 횃불은 **바닥·벽 옆면**에 붙여 놓을 수 있으며 받침을 부수면 떨어집니다.
- **더 많은 블록·아이템**: 횃불·랜턴·울타리·꽃·긴 풀·밀·당근·모닥불·빛돌·TNT·사암·석재 벽돌·이끼 낀 조약돌·건초·책장·작업대·화로·호박·색깔 양털 등 블록, 금·에메랄드 광석, 나무/돌/철/금/다이아 **곡괭이·삽·도끼**(맞는 블록을 훨씬 빨리 캠), **괭이**(풀·흙 → 경작지), 씨앗·당근·빵·사과·황금사과, **물약**(신속·야간 투시·치유), 부싯돌과 철(TNT 점화, 연쇄 폭발), 나침반·시계, 가죽·금 갑옷. 가방 🎒 의 제작 탭에서 만들 수 있어요.
- **농사**: 괭이로 풀/흙을 갈아 경작지를 만들고 씨앗·당근을 심으면 시간이 지나 자랍니다 (4단계, 다 자라면 수확하면 밀·씨앗/당근이 나와요). 경작지가 아닌 곳엔 심을 수 없습니다.
- 월드 **자동 저장** (고친 블록·가방·핫바·엔드 진행 상황·목표까지. 고친 블록만 기록하는 방식이라 작음) — 앱은 AsyncStorage, 웹은 localStorage
- 시야 거리 4단계, 즉시 채굴, 소리, 낮/밤 전환, 새 월드 (메뉴)
- 세로/가로 화면 모두 지원. 앱은 가로 화면으로 고정합니다(`src/app/index.tsx`, 세로로 쓰려면 그 effect 를 삭제).

## 온라인 저장 (Netlify) · 숨겨진 관리자

`cloud/` 폴더를 Netlify 에 배포하면 게임이 **닉네임으로 접속**하고, 같은 닉네임이면 서버에 저장된 월드가 **다른 기기에서도 이어집니다**. 화면 왼쪽 아래의 흐린 **"관리자"** 버튼은 비밀번호(Netlify 환경 변수 `ADMIN_PASSWORD`)를 입력해 저장된 플레이어를 보고·내려받고·삭제·복원하는 화면으로 들어갑니다. 서버가 없는 곳(파일로 열기·앱)에서는 기존처럼 이 기기에만 저장돼요. 배포 순서와 동작 방식은 [`cloud/README.md`](cloud/README.md).

## 구조

```
game/index.html          게임 전체(엔진 + UI). 단독으로도 실행됨 ← 게임 수정은 여기서
scripts/build-game-html.mjs   game/index.html → src/game/gameHtml.ts (문자열 모듈) 변환
src/game/gameHtml.ts     ⚠ 생성 파일. game/index.html 을 고친 뒤 `npm run build:game`
src/game/                buildHtml(저장 데이터 주입) · messages(게임→앱 메시지) · saveStore(AsyncStorage)
src/components/GameView.tsx       네이티브: react-native-webview
src/components/GameView.web.tsx   웹: iframe(srcDoc) + postMessage
src/app/                 Expo Router 화면 (index = 게임)
cloud/                   Netlify 배포용: 닉네임 저장 API(Functions + Blobs) · 관리자 · 로컬 개발 서버 · 테스트
```

앱과 게임은 `postMessage` 로 통신합니다. 게임은 `{type:'save', data}` 를 보내고, 앱이 저장소에 기록합니다. 시작할 때는 앱이 저장된 월드를 HTML 에 `window.__BLOCKCRAFT_SAVE__` 로 심어 줍니다(저장이 없으면 `null`).

## 알려진 한계 / 다음에 해볼 만한 것

- 몬스터·동물은 단순한 AI입니다(직선 이동 + 1칸 턱 뛰어넘기 + 막히면 옆으로 돌아 보기, 본격적인 길 찾기는 없음). 배고픔, 무기 내구도, 동물 번식, 아이템 상자는 없습니다. 아이템 종류를 추가할 때는 `defItem` 목록의 **끝에** 넣어야 이전 저장 데이터의 아이템 번호가 어긋나지 않습니다.
- 물은 흐르지 않는 정적 블록입니다(블록을 부수면 옆에 물이 있을 때 그 자리가 물로 채워지는 정도).
- 청크 생성/메시 생성은 메인 스레드에서 프레임당 예산을 나눠 처리합니다. 저사양 기기에서는 시야 거리를 줄이세요.
- `app.json` 의 `bundleIdentifier` / `package` (`com.blockcraft.game`)는 임시 값입니다. 스토어에 올리기 전에 바꾸세요.
