블록을 부수고, 쌓고, 나만의 세계를 만들어 보세요

📱 터치

  • 왼쪽 조이스틱: 이동 · ▲ 버튼: 점프 (두 번 누르면 비행)
  • 화면 드래그: 시점 회전
  • 화면 짧게 탭: 블록 놓기
  • 화면 길게 누르기: 블록 부수기
  • 아래 핫바 탭: 블록 선택 (선택된 칸을 다시 탭하면 블록 목록)

👾 몬스터

  • 밤이나 동굴처럼 어두운 곳에서 좀비·크리퍼·스켈레톤이 나타나요
  • 몬스터를 탭(PC는 좌클릭)하면 공격! 크로스헤어가 빨갛게 변해요
  • 좀비·스켈레톤은 햇빛에 타요 · 크리퍼는 다가가면 폭발해서 땅이 파여요
  • ♥가 모두 사라지면 쓰러져요 (잠시 맞지 않으면 회복). 메뉴에서 몬스터를 끌 수 있어요

🐖 동물 · 아이템 · 무기

  • 낮의 풀밭에는 돼지·소·양·닭이 살아요. 사냥하면 고기·가죽·양털·깃털이 떨어져요 (가까이 가면 주워져요)
  • 통나무·돌·석탄·철광석을 캐도 아이템이 나와요. 🎒 가방의 제작 탭에서 검·도끼·활·화살·폭탄·구운 고기를 만들 수 있어요
  • 아이템은 가방에서 핫바에 넣어 써요: 검/도끼는 탭해서 공격, 활은 탭해서 발사(화살 필요), 폭탄은 탭해서 던지기, 음식은 탭해서 먹기 (PC는 우클릭)

🐉 최종 목표: 엔더 드래곤

  • 왼쪽 위 🎯 목표를 눌러(또는 메뉴 → 목표 보기 · Q 키) 단계별 안내를 볼 수 있어요
  • 엔더맨의 엔더 진주 + 크리퍼의 화약 → 엔더의 눈 → 포털 프레임. 프레임 8개를 가운데가 빈 3×3 고리로 바닥에 놓으면 엔드 포털이 열려요
  • 포털 안에 서서 기다리면 엔드로 이동! 높은 기둥 위의 엔드 크리스탈을 부수고 엔더 드래곤을 처치하세요
  • 철/다이아 갑옷은 가방에 있으면 자동으로 입어요 (받는 피해 감소)

⌨️ 키보드 · 마우스

  • 클릭으로 마우스 잠금 · WASD 이동 · Space 점프(두 번=비행) · Shift 하강
  • 좌클릭 부수기 · 우클릭 놓기 · 휠클릭 블록 복사
  • 숫자 1~9 / 휠: 블록 선택 · E: 블록 목록 · F: 비행 · Esc: 메뉴
