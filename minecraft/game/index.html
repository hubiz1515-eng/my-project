블록을 캐서 모으고, 쌓고, 나만의 세계를 만들어 보세요

📱 터치

  • 왼쪽 조이스틱: 이동 · ▲ 버튼: 점프 (두 번 누르면 비행)
  • 화면 드래그: 시점 회전
  • 화면 짧게 탭: 손에 든 것 쓰기 (블록 놓기 · 공격 · 먹기)
  • 화면 길게 누르기: 블록 캐기 (캔 블록은 아이템으로 떨어져 가방에 들어와요)
  • 아래 핫바 탭: 손에 들 것 고르기 (선택된 칸을 다시 탭하면 🎒 가방)
  • 블록은 무한이 아니에요: 캐거나 만든 만큼만 놓을 수 있어요. 광석은 캐면 자원(다이아·금·석탄…)이 나와요

👾 몬스터

  • 밤이나 동굴처럼 어두운 곳에서 좀비·크리퍼·스켈레톤이 나타나요
  • 몬스터를 탭(PC는 좌클릭)하면 공격! 크로스헤어가 빨갛게 변해요
  • 좀비·스켈레톤은 햇빛에 타요 · 크리퍼는 다가가면 폭발해서 땅이 파여요
  • ♥가 모두 사라지면 쓰러져요 (잠시 맞지 않으면 회복). 메뉴에서 몬스터를 끌 수 있어요

🐖 동물 · 아이템 · 무기

  • 낮의 풀밭에는 돼지·소·양·닭이 살아요. 사냥하면 고기·가죽·양털·깃털이 떨어져요 (가까이 가면 주워져요)
  • 통나무·돌·석탄·철광석을 캐면 아이템이 나와요. 🎒 가방의 제작 탭에서 검·도끼·활·화살·폭탄·구운 고기, 나무 판자·유리·벽돌 같은 건축 블록도 만들 수 있어요
  • 아이템은 가방에서 핫바에 넣어 써요: 검/도끼는 탭해서 공격, 활은 탭해서 발사(화살 필요), 폭탄은 탭해서 던지기, 음식은 탭해서 먹기 (PC는 우클릭)

🏘 마을 · 주민 · 새 아이템

  • 풀밭·사막 어딘가에 마을이 있어요. 🧭 나침반(철 3 + 금 1)을 들면 가장 가까운 마을의 방향과 거리가 나와요
  • 주민을 탭하면 거래해요. 에메랄드(광석·거래)로 철 도구, 횃불, 나침반, 물약, 황금 사과 등을 살 수 있어요 (주민은 다치지 않아요)
  • 🔦 횃불(석탄+막대)은 벽·바닥에 붙여서 주변을 밝혀요. 밝은 곳에는 몬스터가 안 나와요. 랜턴 · 모닥불 · 빛돌도 있어요
  • ⛏ 곡괭이·삽·도끼는 알맞은 블록을 훨씬 빨리 캐요. 괭이로 흙을 갈고 씨앗·당근을 심으면 밀·당근이 자라요
  • 💥 TNT는 부싯돌과 철(철 1 + 부싯돌 1)로 불을 붙여요. 자갈을 캐면 부싯돌이 나와요

🐉 최종 목표: 엔더 드래곤

  • 왼쪽 위 🎯 목표를 눌러(또는 메뉴 → 목표 보기 · Q 키) 단계별 안내를 볼 수 있어요
  • 엔더맨의 엔더 진주 + 크리퍼의 화약 → 엔더의 눈 → 포털 프레임. 프레임 8개를 가운데가 빈 3×3 고리로 바닥에 놓으면 엔드 포털이 열려요
  • 포털 안에 서서 기다리면 엔드로 이동! 높은 기둥 위의 엔드 크리스탈을 부수고 엔더 드래곤을 처치하세요
  • 철/다이아 갑옷은 가방에 있으면 자동으로 입어요 (받는 피해 감소)

⌨️ 키보드 · 마우스

  • 클릭으로 마우스 잠금 · WASD 이동 · Space 점프(두 번=비행) · Shift 하강
  • 좌클릭 캐기·공격 · 우클릭 놓기(손에 든 것 쓰기) · 휠클릭 가방에 있는 블록 가져오기
  • 숫자 1~9 / 휠: 손에 들 것 선택 · E: 가방 · F: 비행 · Esc: 메뉴
